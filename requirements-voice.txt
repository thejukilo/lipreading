# Voice cloning (optional) — install separately AFTER the main requirements so it
# doesn't disturb your CUDA torch build:
#
#   pip install -r requirements-voice.txt
#
# coqui-tts provides XTTS v2 (zero-shot cloning). First synthesis downloads the
# ~1.8GB model to your TTS cache. The XTTS v2 model license (CPML) is
# NON-COMMERCIAL — fine for personal use; swap the backend for a product.
#
# If pip wants to change your installed torch, pin torch to your current version
# on the same command, e.g.:
#   pip install -r requirements-voice.txt torch==<your-version>
# Keep coqui-tts and transformers aligned: each coqui-tts release pins a
# transformers range and imports version-specific symbols, so a mismatched
# transformers fails at import. The latest coqui-tts (0.27.x) requires
# transformers>=4.57. If you install a different coqui-tts version, install the
# transformers it asks for instead (check: pip show coqui-tts).
coqui-tts>=0.27
# MUST cap below 5.0: transformers 5.x removed the compat shims coqui-tts 0.27.x
# imports (e.g. isin_mps_friendly), and a bare ">=4.57" installs the latest 5.x.
transformers>=4.57,<5
